# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, sales trends, and business insights.

The project uses Python for data loading, Exploratory Data Analysis (EDA), and data cleaning. SQL is used to perform business-related queries, while Power BI is used to create interactive dashboards for data visualization.

The final insights are presented through a structured analytical report and a PowerPoint presentation created using Gamma.

**Project Goal:** Transform raw customer shopping data into meaningful insights that support better business and marketing decisions.

## 🔄 Project Workflow

### 1. Data Loading
- Imported the dataset into Python using Pandas.
- Loaded the CSV file into a DataFrame.
- Inspected the dataset using `head()`, `info()`, and `describe()`.

### 2. Exploratory Data Analysis (EDA)
- Analyzed dataset structure and data types.
- Examined numerical and categorical columns.
- Identified missing values.
- Explored customer demographics and purchasing behavior.

### 3. Data Cleaning and Transformation
- Checked for missing and null values.
- Handled missing review ratings using the median rating of each product category.
- Renamed column names into snake_case format.
- Created age groups using age-based quartiles.
- Converted purchase frequency into numerical days.
- Removed the redundant `promo_code_used` column after checking its values against `discount_applied`.

### 4. SQL Analysis

Connected the cleaned dataset to a relational database and performed SQL queries to answer important business questions.

**Business Questions Analyzed:**

1. What is the total revenue generated by male and female customers?
2. Which customers used discounts but spent more than the average purchase amount?
3. What are the top five products with the highest average review ratings?
4. How do average purchase amounts compare between Standard and Express Shipping?
5. Do subscribed customers spend more than non-subscribed customers?
6. Which five products have the highest discount usage percentage?
7. How many customers belong to New, Returning, and Loyal segments?
8. What are the top three most purchased products in each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?

**SQL Concepts Used:**
- SELECT, WHERE, GROUP BY
- ORDER BY
- Aggregate Functions (SUM, AVG, COUNT)
- Subqueries
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions (ROW_NUMBER)

## ⚙️ How to Run the Project

### Prerequisites

Install the following tools:

- Python 3.x
- Jupyter Notebook
- PostgreSQL / MySQL / SQL Server
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/customer-shopping-behavior-analysis.git
```

### Step 2: Navigate to the Project Folder

```bash
cd customer-shopping-behavior-analysis
```

### Step 3: Install Required Python Libraries

```bash
pip install pandas numpy sqlalchemy psycopg2-binary pymysql pyodbc jupyter
```

### Step 4: Add the Dataset

Place `customer_shopping_behavior.csv` in the project directory.

### Step 5: Run the Jupyter Notebook

```bash
jupyter notebook
```

Open `Customer_Shopping_Behavior_Analysis.ipynb` and execute the cells step by step.

### Step 6: Connect to the Database

- Create a database named `customer_behavior`.
- Update the database username, password, host, and port in the notebook.
- Run the appropriate database connection section.
- Load the cleaned DataFrame into the `customer` table.

### Step 7: Execute SQL Queries

Open the SQL query file in your database client and execute the business analysis queries.

### Step 8: Open the Power BI Dashboard

Open the `.pbix` file in Power BI Desktop and refresh the data connection if required.
